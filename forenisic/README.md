# Forensic UI (Next.js)

Interview-style forensic composite UI for this repo.

## Run

```bash
cd Forensic-Sketch-Generator/forenisic
npm install
npm run dev
```

Open **http://localhost:3000**

## What is wired

- Home page → `components/forensic.tsx` (MCQ interview UI)
- Design tokens → `app/globals.css`
- UI primitives → `components/ui/*`
